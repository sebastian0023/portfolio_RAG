Trail Planner is a small web app that plans multi-day hikes from public map data.

## What it does

It suggests daily stages based on distance and elevation gain. It exports the plan as a printable page.

## How it was built

The front end is Angular and the back end is a single serverless function. The project is open source and has a short README.
