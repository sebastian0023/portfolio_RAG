Alex Example worked at Acme Robotics from 2021 to 2024 as a software engineer. The team built fleet-management tools for warehouse robots.

## Responsibilities

- Designed a telemetry pipeline that handled about two thousand events per second.
- Wrote the on-call runbook and reduced paging noise by tuning alert thresholds.

## Technologies

The work used TypeScript, PostgreSQL, and Kubernetes. Alex also introduced contract tests between services.
