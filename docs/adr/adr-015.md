# ADR-015: Verify JWT inside Lambda with aws-jwt-verify; custom header; SPA memory

Status: Partly superseded by ADR-051. There is no JWT or Cognito. The `X-Auth-Token` header and the rule that it is kept in SPA memory only carry the signed guest pass (ADR-052).

## Context

OAC needs Authorization for SigV4 and tokens must avoid persistent browser storage.

## Decision

Verify JWT inside Lambda with aws-jwt-verify; custom header; SPA memory.

## Consequences

X-Auth-Token proposed; verify issuer/client/token use/expiry; do not persist tokens or accept identity claims before verification.
