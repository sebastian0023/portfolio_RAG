# ADR-035: GitHub Environment apply approval, Lambda versions/live alias rollback, tiny post-deploy smoke

Status: Accepted (Phase 0)

## Context

Single-stack updates need an auditable release gate.

## Decision

GitHub Environment apply approval, Lambda versions/live alias rollback, tiny post-deploy smoke.

## Consequences

Check private-repo plan entitlement; version artifacts together; leave deployment disabled if required gate cannot be enforced.
