# ADR-033: Protect state bucket, Cognito pool, DynamoDB table, S3/vector buckets

Status: Accepted (Phase 0)

## Context

Accidental replacement can destroy production data.

## Decision

Protect state bucket, Cognito pool, DynamoDB table, S3/vector buckets.

## Consequences

Terraform prevent_destroy plus native deletion protection where supported; protected deletion workflow for any necessary migration.
