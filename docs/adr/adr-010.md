# ADR-010: Playwright for e2e

Status: Accepted (Phase 0)

## Context

Browser behavior and streaming need user-level verification.

## Decision

Playwright for e2e.

## Consequences

Mocked UI smoke in Phase 2; local full-stack journeys in Phase 6; tightly bounded deployed smoke.
