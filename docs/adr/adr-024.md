# ADR-024: Lambda reserved concurrency and about 400 max output tokens

Status: Accepted (Phase 0)

## Context

Bound concurrent generation and per-response expense.

## Decision

Lambda reserved concurrency and about 400 max output tokens.

## Consequences

Deadline, input/context caps, and retry ceilings complement the output cap; reasoning/billed-token differences must be measured.
