# ADR-006: One module per concern: bootstrap, oidc, edge, web, api, auth, storage, vectors, budgets, ssm, observability

Status: Accepted (Phase 0)

## Context

Keep permissions and resource responsibilities visible.

## Decision

One module per concern: bootstrap, oidc, edge, web, api, auth, storage, vectors, budgets, ssm, observability.

## Consequences

Bootstrap root belongs in infra/bootstrap; reusable concerns under infra/modules; narrow inputs/outputs and no circular modules.
