# ADR-022: evals/policy.yaml selects cheapest model passing all thresholds; injection score breaks ties

Status: Accepted (Phase 0)

## Context

Low price must not excuse failed quality/security gates.

## Decision

evals/policy.yaml selects cheapest model passing all thresholds; injection score breaks ties.

## Consequences

Version thresholds before comparison; fail closed when none qualify; record cost basis, uncertainty, and selected model evidence.
