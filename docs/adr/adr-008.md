# ADR-008: GitHub Actions → AWS OIDC; no long-lived keys

Status: Accepted (Phase 0)

## Context

CI should not store permanent AWS credentials.

## Decision

GitHub Actions → AWS OIDC; no long-lived keys.

## Consequences

Scope repo/ref/environment claims; separate plan/apply/eval roles; retain temporary human bootstrap path.
