# ADR-051: Guests only: no accounts, a per-IP daily quota, and a site-wide cap

Status: Accepted (Phase 4, owner decision 2026-10-04).

## Context

The original plan gave signed-in visitors a higher daily quota through a Cognito user pool (ADR-014), verified JWTs (ADR-015), and per-user limits (ADR-025), plus an admin path protected by MFA. A portfolio assistant gets a handful of visitors, nearly all of whom will not create an account to ask more questions. Accounts would add a critical risk (R-11, social-only admin MFA), a pricing question (R-05), JWT middleware, and sign-in states in the UI, in exchange for one quota tier.

## Decision

1. There are no accounts. Cognito, JWT verification, and the sign-in flow are not built. Admin actions (switching `chat_enabled`, deploying, changing limits) stay operator-run through the MFA-gated AWS role.
2. Every visitor is a guest with **10 questions per IP bucket per day** (`limits.guestPerIpPerDay`). The bucket is an IPv4 address or an IPv6 /64, from the trusted CloudFront viewer address (ADR-016).
3. A site-wide **global daily quota of 50** (`limits.globalPerDay`) is a permanent hard stop on spend. It replaces the temporary cap of ADR-050. At the worst case of $0.0088 per answer with retrieval, 50 a day for 30 days is about $13 a month, so the Bedrock monthly budget (the kill switch) rises from $10 to $15.
4. A guest question reserves the per-IP and global counters in one atomic transaction, before the first paid call, and never refunds (abuse-budgets.md). A visitor over the per-IP limit gets `quota_exhausted`; the global limit gives `site_limit`.
5. Bot protection is Cloudflare Turnstile, verified on the server, which then issues a signed one-hour guest pass (ADR-052). The `X-Auth-Token` header that the edge already forwards carries the pass.
6. The shared contract drops what accounts needed: the `user` principal (`QuotaState` is `{left, limit}`), the `auth_expired` error code, and every sign-in state in the SPA.

## Consequences

- Phase 4 shrinks to Turnstile, the guest pass, per-IP and global quotas, and the cost-abuse tests. Tasks P4-01, P4-02, and P4-05 are cancelled.
- R-05 (Cognito pricing) and R-11 (social-only admin MFA) no longer apply. R-18 (secrets in Terraform state) still does, for the two new secrets.
- Visitors who share an IP (an office, a mobile carrier) share 10 questions. That is the accepted trade for having no identity.
- If accounts are ever wanted, they can be added behind the same `X-Auth-Token` seam without changing the stream contract.
