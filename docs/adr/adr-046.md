# ADR-046: Protected main; integration/deploy dev; phase branches/PRs/tags; Conventional Commits; final release only to main

Status: Accepted (Phase 0)

## Context

Work must remain phased and reviewable.

## Decision

Protected main; integration/deploy dev; phase branches/PRs/tags; Conventional Commits; final release only to main.

## Consequences

Follow workflow above; dev default during build; phase exit checklists; tag/update/smoke per phase; Phase 7 release PR, v1.0.0, then deploy main. Owner-approved Phase 0 exception: initialize the skeleton directly on the existing portfolio_RAG main branch; resume dev and phase PR workflow after initialization.
