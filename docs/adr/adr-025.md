# ADR-025: Per-user and global daily limits

Status: Accepted (Phase 0)

## Context

Distributed attackers can evade identity-only limits.

## Decision

Per-user and global daily limits.

## Consequences

Atomic admission before paid work; count failed/aborted attempts conservatively; guest and authenticated totals share the global cap.
