# ADR-013: CloudFront with private S3 OAC and /api/* Lambda origin

Status: Accepted (Phase 0)

## Context

Serve UI and API from one edge domain.

## Decision

CloudFront with private S3 OAC and /api/* Lambda origin.

## Consequences

Separate behaviors/policies; API caching disabled; private S3; SPA fallback cannot swallow API failures.
