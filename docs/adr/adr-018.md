# ADR-018: Amazon S3 Vectors, 512 dimensions, cosine, immutable index configuration

Status: Accepted (Phase 0)

## Context

Match Titan embedding size at low storage cost.

## Decision

Amazon S3 Vectors, 512 dimensions, cosine, immutable index configuration.

## Consequences

Schema/dimension/metric changes need new indexes; enforce metadata limits in ingestion.
