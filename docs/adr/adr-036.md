# ADR-036: Hexagonal architecture; business logic never imports AWS SDKs; core cannot import adapters

Status: Accepted (Phase 0)

## Context

Keep behavior independently testable and replaceable.

## Decision

Hexagonal architecture; business logic never imports AWS SDKs; core cannot import adapters.

## Consequences

ESLint boundaries fail forbidden imports; dependencies point through ports; adapters own SDK details.
