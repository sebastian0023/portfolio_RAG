# ADR-028: Metadata-only logs, never full prompts by default; 14-day CloudWatch retention

Status: Accepted (Phase 0)

## Context

Reduce privacy exposure and storage cost.

## Decision

Metadata-only logs, never full prompts by default; 14-day CloudWatch retention.

## Consequences

Log latency/token counts/retrieval scores and safe IDs; redact auth/Turnstile tokens, text, exception payloads; no verbose request logs.
