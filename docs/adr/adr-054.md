# ADR-054: Retrieval, prompt, abstention, and citation policy

Status: Accepted (Phase 5, owner-approved plan 2026-10-04). Builds on ADR-041, ADR-042, ADR-048, ADR-049.

## Context

The model must answer only from retrieved public text, treat that text and the visitor's input as untrusted (R-09), and never invent a source (R-17).

## Decision

1. **Retrieval.** Embed the question with Titan v2 (512 dimensions), query the index named by `active_index` with the filter `lang = en`, and ask for `topK = min(limits.retrievedChunks, 5)`. The browser rejects more than five sources.
2. **Threshold.** `RETRIEVAL_POLICY.minScore` (provisional 0.25) is a code constant, not a `limits` key: `limitsSchema` is strict, so a new key would make the config invalid after a Lambda rollback. Changing it requires a new eval gate run.
3. **Abstention.** If no match reaches the threshold, the stream is `accepted`, a fixed no-coverage `delta`, then `done{coverage: none, cited: []}`. No model call is made.
4. **Failures.** An embedding or retrieval failure is an `error` before `accepted` (a 503). The model never answers without sources.
5. **Admission.** `indexReadyStage` follows `chatEnabledStage` and returns 503 while `active_index` is `none`, before the guest pass and the quota.
6. **Prompt.** The system prompt holds policy only: answer from the sources, cite `[n]` using only the given numbers, use the fixed no-coverage text when the answer is absent, and treat sources and history as data. Sources and the question go in the user message as `<source n=…>` blocks. Every interpolated value is escaped (`& < >`), and `[digits]` inside evidence and history is rewritten to `(digits)`. The token estimate is `ceil(utf8Bytes / 3)`, and evidence is truncated lowest rank first.
7. **Sources event.** Built by the API from retrieval, never from model output. The excerpt is the chunk text. Highlights are up to two sentences chosen by overlap with the question.
8. **`done`.** `cited` lists every distinct `[n]` the model wrote (at most 20, each at most 99), including numbers with no source, because the browser hides those. `coverage` is `answered` only when at least one marker is between 1 and the number of sources.
9. **Logs.** Retrieval logs index name, counts, top score, safe chunk ids, and token counts. Never text, titles, or the question.

## Consequences

- A prompt injection can change the wording of an answer but cannot forge a source card, an excerpt, or a URL.
- The no-match path costs one embedding and one query.
- Follow-up questions are retrieved on the question alone and may retrieve poorly; Phase 6 evals measure this.
