# ADR-020: Bedrock Titan Text Embeddings v2 at 512 dimensions

Status: Accepted (Phase 0)

## Context

Stable embedding family for ingestion and queries.

## Decision

Bedrock Titan Text Embeddings v2 at 512 dimensions.

## Consequences

Same model/config for both paths; test vector length; quantify ingestion and per-query embedding costs.
