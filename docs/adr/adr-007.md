# ADR-007: S3 remote state, lockfile, encryption, versioning

Status: Accepted (Phase 0)

## Context

One production stack needs concurrency control and recovery.

## Decision

S3 remote state, lockfile, encryption, versioning.

## Consequences

Bootstrap before remote init; minimal state access; retain versions; native S3 lockfile, not a separate lock table.
