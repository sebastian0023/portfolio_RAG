# ADR-041: Facade + Template Method for RagService

Status: Accepted (Phase 0)

## Context

A common RAG sequence should survive adapter changes.

## Decision

Facade + Template Method for RagService.

## Consequences

Fixed orchestration stages with replaceable ports; central budget/context/citation policy.
