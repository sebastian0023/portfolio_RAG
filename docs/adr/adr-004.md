# ADR-004: Lambda Function URL with SSE response streaming and AWS_IAM through OAC

Status: Accepted (Phase 0)

## Context

Low-cost browser streaming requires a protected origin.

## Decision

Lambda Function URL with SSE response streaming and AWS_IAM through OAC.

## Consequences

Adapt Hono/Lambda response streaming; verify headers/hash; direct unauthorized URL invocation denied.
