# ADR-023: SSM Parameter Store; Turnstile secret SecureString; AWS-managed keys, no customer KMS keys

Status: Accepted (Phase 0)

## Context

Minimize secret exposure and recurring key costs.

## Decision

SSM Parameter Store; Turnstile secret SecureString; AWS-managed keys, no customer KMS keys.

## Consequences

Scope SSM decrypt access; do not put secret values in Terraform source, output, plans, or logs; service-managed/default encryption where appropriate.
