# ADR-038: Repository for IndexRepository with S3 Vectors adapter and in-memory fake

Status: Accepted (Phase 0)

## Context

Retrieval logic must be testable without AWS.

## Decision

Repository for IndexRepository with S3 Vectors adapter and in-memory fake.

## Consequences

Fake and remote adapter share contract tests; avoid claiming fake tests verify service limits.
