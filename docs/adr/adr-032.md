# ADR-032: One stack, dedicated AWS account, env default prod in names

Status: Accepted (Phase 0)

## Context

Isolation comes from account and workflow rather than staging.

## Decision

One stack, dedicated AWS account, env default prod in names.

## Consequences

No staging account/stack instantiated; quota, budget, and blast-radius ownership must be explicit.
