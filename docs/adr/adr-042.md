# ADR-042: Builder for PromptBuilder

Status: Accepted (Phase 0)

## Context

Prompt construction needs bounded, auditable steps.

## Decision

Builder for PromptBuilder.

## Consequences

Separate system policy, question, history, untrusted evidence; enforce token budget and citation format.
