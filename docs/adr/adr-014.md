# ADR-014: Cognito User Pool Hosted UI, Authorization Code + PKCE, social only; anonymous + optional sign-in + admin

Status: Accepted (Phase 0)

## Context

Visitors can try chat before signing in.

## Decision

Cognito User Pool Hosted UI, Authorization Code + PKCE, social only; anonymous + optional sign-in + admin.

## Consequences

Turnstile for guests; higher signed-in quotas; no passwords or Identity Pool guest credentials; admin group needs MFA assurance.
