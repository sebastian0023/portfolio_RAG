# ADR-044: TypeScript strict and Zod config validation at startup and all trust boundaries

Status: Accepted (Phase 0)

## Context

Types alone cannot validate remote input.

## Decision

TypeScript strict and Zod config validation at startup and all trust boundaries.

## Consequences

Fail fast on invalid deployment config; validate input, claims mapping, SSM, metadata, provider output, and events.
