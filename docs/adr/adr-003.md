# ADR-003: Node + TypeScript, ARM64 Lambda, Hono

Status: Accepted (Phase 0)

## Context

Fully serverless runtime with low operations overhead.

## Decision

Node + TypeScript, ARM64 Lambda, Hono.

## Consequences

Verify runtime/ARM dependency compatibility; strict typed composition root; no application server fleet.
