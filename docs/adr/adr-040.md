# ADR-040: Decorator for logging, metrics, timing

Status: Accepted (Phase 0)

## Context

Observability should not contaminate business logic.

## Decision

Decorator for logging, metrics, timing.

## Consequences

Metadata-only wrappers; preserve stream cancellation, exceptions, and usage semantics.
