# ADR-001: Angular SPA, no SSR

Status: Accepted (Phase 0)

## Context

Portfolio has static profile content and interactive chat.

## Decision

Angular SPA, no SSR.

## Consequences

Serve build from private S3; no rendering server; review client-side SEO/accessibility during launch.
