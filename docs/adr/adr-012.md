# ADR-012: npm workspaces monorepo

Status: Accepted (Phase 0)

## Context

Share contracts without additional orchestration complexity.

## Decision

npm workspaces monorepo.

## Consequences

apps/web, apps/api, packages/shared, infra, knowledge, evals, docs; no Nx; one lockfile.
