# ADR-048: Citations carry a bounded public excerpt; one stream contract for the mock and the API

Status: Accepted (Phase 2, owner decision 2026-10-04).

## Context

The design's source viewer shows the cited passage with the sentences used in the answer highlighted. `Citation` in `packages/shared` was defined as a reference to a retrieved chunk "without exposing its text", which would leave the viewer with nothing to show. Phase 2 also needs a mock backend whose events the real API can later reproduce unchanged (P2-05).

The knowledge corpus is public-only (ADR-031): every file is reviewed as publicly readable.

## Decision

1. `packages/shared/src/chat-stream.ts` defines the browser-facing contract: `ChatRequest`, `ChatStreamEvent` (`accepted`, `sources`, `delta`, `done`, `error`), `QuotaState`, `ChatErrorCode`, and `SourceCitation`.
2. `SourceCitation` extends `Citation` with `n` (the number used by inline `[n]` markers), `title`, `section`, `path`, `updated`, and a bounded `excerpt` (at most 600 characters) with `highlights` as character ranges inside the excerpt. `Citation` itself stays text-free for the backend.
3. The browser validates every event with the Zod schema in `chat-stream-schema.ts` (ADR-044). The schema accepts only `https` source links and rejects highlight ranges outside the excerpt. It lives in a separate module so code that needs only the types does not bundle zod.
4. A failure before any bytes reach the server (no connection) is not an event. The transport throws, and the UI treats it as a network problem. Errors the server decides (quota, rate, validation, availability) are `error` events.
5. The Phase 2 mock transport emits exactly these events. Phase 3 replaces it with an HTTP adapter and keeps the facade, components, and tests. The wire format and status semantics are in ADR-049.

## Consequences

- Excerpts are public by policy, so sending them is allowed. The ingestion step (Phase 5) must produce excerpts and highlight ranges from reviewed chunks only, and the corpus review gate in ADR-031 covers them.
- The model never supplies excerpts or source metadata. The API fills them from retrieval, so a prompt injection cannot forge a source card.
- The model supplies only text with `[n]` markers. The UI honors a marker only when a matching source arrived first; any other bracketed text renders as plain text.
- Changing an event shape is a contract change: update the schema, the mock, and this ADR together.

## Amendment (Phase 5, ADR-054)

Chunks are at most 600 characters and the chunk text is the excerpt. Highlights are computed by the API from the question, because `sources` is sent before the answer exists.
