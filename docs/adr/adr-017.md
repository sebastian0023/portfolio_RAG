# ADR-017: DynamoDB on-demand + TTL rate limits by Cognito sub or IP

Status: Accepted (Phase 0). Amended by ADR-051: counters are keyed by the trusted IP bucket and the global day only; there is no Cognito `sub`.

## Context

Distributed Lambda workers need shared abuse counters.

## Decision

DynamoDB on-demand + TTL rate limits by Cognito sub or IP.

## Consequences

Atomic conditions/transactions; explicit window expiry; TTL only cleans old items; test races and failure behavior.
