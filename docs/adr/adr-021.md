# ADR-021: LLM is SSM config, not fixed; Haiku 4.5 runtime and Gemma 4 26B-A4B mantle are candidates

Status: Accepted (Phase 0)

## Context

Price/quality may change independently of application code.

## Decision

LLM is SSM config, not fixed; Haiku 4.5 runtime and Gemma 4 26B-A4B mantle are candidates.

## Consequences

Provider registry and endpoint-specific adapters; only allow validated candidate configurations; Phase 3 Haiku is provisional.
