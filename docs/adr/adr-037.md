# ADR-037: Strategy + Adapter + Registry for LLMProvider

Status: Accepted (Phase 0)

## Context

Multiple model endpoints expose different protocols.

## Decision

Strategy + Adapter + Registry for LLMProvider.

## Consequences

Stable normalized contract; registry uses validated IDs; AWS credentials and endpoint details remain adapter concerns.
