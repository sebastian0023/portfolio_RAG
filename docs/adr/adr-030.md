# ADR-030: No SQS in v1

Status: Accepted (Phase 0)

## Context

Ingestion and request paths fit bounded direct workflows.

## Decision

No SQS in v1.

## Consequences

Use CI ingestion with bounded retries/checkpointing; do not introduce a queue without a new decision.
