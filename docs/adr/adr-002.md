# ADR-002: Signals, facade services, smart/presentational components

Status: Accepted (Phase 0)

## Context

UI needs predictable streaming state.

## Decision

Signals, facade services, smart/presentational components.

## Consequences

ChatFacade owns state and transport coordination; presentational components receive typed inputs/events.
