# ADR-009: Vitest for all TypeScript unit and integration tests

Status: Accepted (Phase 0)

## Context

Avoid multiple TS test frameworks.

## Decision

Vitest for all TypeScript unit and integration tests.

## Consequences

Angular runner must use Vitest; backend and shared packages use Vitest; pytest only if Python is later introduced, which is not planned.
