# ADR-034: Replace staging with local handler evals using candidate index/real Bedrock, and local Playwright with test JWT

Status: Accepted (Phase 0). Amended by ADR-051: there is no test JWT; local browser tests use Turnstile's published dummy keys and a stubbed pass.

## Context

Need confidence without duplicate production infrastructure.

## Decision

Replace staging with local handler evals using candidate index/real Bedrock, and local Playwright with test JWT.

## Consequences

Restrict eval credentials and spend; production cannot trust local issuer/keys; passing local tests does not prove AWS integration.

## Amendment (Phase 5, ADR-053)

The candidate eval tool runs as the dedicated `portfolio-v2-prod-eval` role and writes a report (metrics only, no answer text). `promote` refuses a candidate without a passing, recent report.
