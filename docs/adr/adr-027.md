# ADR-027: SSM chat_enabled off switch

Status: Accepted (Phase 0)

## Context

Operator needs to stop inference without a deployment.

## Decision

SSM chat_enabled off switch.

## Consequences

Default false before readiness; bounded cache delay; fail closed on missing/invalid config; external operator path remains usable if API is stopped.
