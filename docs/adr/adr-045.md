# ADR-045: Contract suite required for every LLMProvider and IndexRepository adapter

Status: Accepted (Phase 0)

## Context

Swaps must preserve semantics, not only signatures.

## Decision

Contract suite required for every LLMProvider and IndexRepository adapter.

## Consequences

Cover streaming, cancellation, errors, usage, filters, dimensions, ordering, absence, and citation metadata as applicable.
