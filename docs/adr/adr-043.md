# ADR-043: Dependency injection through one composition root per app

Status: Accepted (Phase 0)

## Context

Environment choices must be explicit.

## Decision

Dependency injection through one composition root per app.

## Consequences

Construct adapters at app boundary; no service-locator access from core; production rejects fake/test wiring.
