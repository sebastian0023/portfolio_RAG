# ADR-016: Cheapest-first middleware: validate → rate limit → auth → RagService

Status: Accepted (Phase 0)

## Context

Reject bad requests before expensive checks or inference.

## Decision

Cheapest-first middleware: validate → rate limit → auth → RagService.

## Consequences

Pre-auth counters use trusted IP/global keys; verified-sub quotas finalize after authentication; record this trust-boundary refinement explicitly.
